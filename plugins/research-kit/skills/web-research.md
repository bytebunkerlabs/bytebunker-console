# Web research discipline

1. Every factual claim comes from a page you fetched in this session. Cite the exact URL, with a short quote of the passage that supports it.
2. Fetch at least two independent sources for anything load-bearing. If they disagree, report the disagreement rather than pick a winner silently.
3. Note publication dates when the topic is time-sensitive.
4. A page that fails to load is an unknown, not a licence to answer from memory.
5. Distill: report findings and sources, not page dumps.
