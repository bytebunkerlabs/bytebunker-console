A skill is a Markdown file of instructions: how to review code here, how to write a release note, which commands to use. Attach skills to a chat and their text goes into the system prompt, ahead of your own.

Create one on [Skills](#skills); it is saved in your data folder, never inside the app. Skills are shared with the agents.
