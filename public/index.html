Jobs
The console wakes up on a schedule and the model does the work · —

      

        

        
Pick a job to see its runs and what the model produced. A chat job is one prompt with the console's tools and skills; an agent job hands a goal to the harness. Times are the console host's local time.

      

    


    
    

      
Workflows
A prompt you run again, with blanks to fill: from here, from a job, or with bb run · —

      

        

        
Pick a workflow to run it. Write {{name}} in a prompt and the run asks for it: bb run review -p file=app.py. A chat workflow is one turn with your tools and skills; an agents workflow is a goal for the agents.

      

    


    
    

      
MCP
Local tool servers the model calls through the console · —

      

        

        
Pick a server to see its tools, or add one from the catalog. "Install locally" pre-installs the package (and for Playwright the Chromium build) on this host, then adds the server; the log streams here.
